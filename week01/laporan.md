# Laporan Praktikum Jaringan Komputer

Langkah yang dilakukan:

1. Menginstal aplikasi **Wireshark** di laptop.
2. Membuka Wireshark lalu memilih **Wi-Fi** untuk mulai menangkap paket jaringan.
3. Setelah capture dimulai, membuka link yang diberikan di web browser:

   http://gaia.cs.umass.edu/wireshark-labs/INTRO-wireshark-file1.html

4. Setelah halaman web terbuka, kembali ke Wireshark lalu **menghentikan capture**.
5. Menggunakan filter **http** untuk menampilkan paket HTTP.
6. Setelah filter digunakan, terlihat paket dari website yang tadi dibuka.
7. Pada hasil tersebut muncul **status "200 OK"** yang berarti halaman web berhasil dimuat.

### Kesimpulan

Dari praktikum ini dapat dipahami bahwa Wireshark dapat digunakan untuk melihat aktivitas jaringan saat membuka website. Status **200 OK** menunjukkan bahwa permintaan ke server berhasil.
